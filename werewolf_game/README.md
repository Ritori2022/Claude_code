# 🌙 AI多人格狼人杀游戏系统

> 让具有不同性格的AI代理们进行社交推理和互相欺骗!

## ✨ 特色功能

### 🎭 6位独特性格的AI代理

1. **逻辑学家·阿尔法** - 理性冷静,依靠数据和概率推理
2. **直觉派·贝塔** - 感性判断,相信第六感
3. **话痨·伽马** - 话多,喜欢发散思维和混淆视听
4. **沉默者·德尔塔** - 少言寡语,通过观察推理
5. **戏精·艾普西隆** - 情绪化表达,擅长演技
6. **老好人·泽塔** - 和平主义者,不喜欢冲突

### 🎮 游戏角色

- 🐺 **狼人** × 2 - 夜晚击杀村民
- 🔮 **预言家** × 1 - 夜晚可验一人身份
- 💊 **女巫** × 1 - 拥有解药和毒药
- 🏹 **猎人** × 1 - 死后可带走一人
- 👥 **村民** × 1 - 依靠推理找出狼人

### 🎯 游戏流程

1. **夜晚阶段**
   - 狼人击杀目标
   - 预言家验人
   - 女巫使用药剂

2. **白天阶段**
   - 公布死讯
   - 自由讨论
   - 投票放逐

3. **胜利条件**
   - 好人阵营:消灭所有狼人
   - 狼人阵营:狼人数 ≥ 好人数

## 🚀 快速开始

### 运行游戏

```bash
cd werewolf_game
python werewolf.py
```

### 观看AI们的精彩推理

游戏会自动进行,你可以观察:
- 不同性格AI的发言风格
- 狼人如何伪装
- 预言家如何引导
- 投票时的博弈策略

## 🎨 架构设计

```
WerewolfGame (游戏控制器)
    ├── Player (玩家)
    │   ├── AgentPersonality (性格系统)
    │   └── Role (角色)
    ├── NightPhase (夜晚逻辑)
    ├── DayPhase (白天逻辑)
    └── VoteSystem (投票系统)
```
